Each student's home directory has owner-only permissions (700), so nobody else can list or read it; privacy does not depend on trust. Sharing is separate: every group project gets its own directory owned by a project group, with the setgid bit so new files stay in that group. Members reach it through a link in their home, so only one copy exists. Only listed members can read or write, and the owner can remove a member at any time. Course drop-boxes accept submissions but hide other students' files. Privacy is the default; sharing is explicit, narrow and revocable.
